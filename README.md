# Je cours pour ma Forme — Front SkillCamp

Front statique destiné aux exercices JavaScript / backend.

## Pages
- `index.html` : liste des courses + filtres
- `inscription.html` : formulaire d'inscription
- `admin.html` : espace organisateur
- `styleguide.html` : composants disponibles

## JavaScript
- `js/races.js` : jeu de données de départ
- `js/app.js` : fichier de travail volontairement quasi vide

## Démarrage
Ouvrir `index.html` directement, ou servir le dossier avec un serveur local.

Les images utilisent Unsplash à distance afin de garder le package léger.
